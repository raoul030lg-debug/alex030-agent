# Elektriker Website Skill

## Design-Regeln

- **Primärfarbe:** Elektrisches Gelb (#f5c518) oder Warngelb (#f0a500) auf Dunkel (#080808)
- **Alternativ:** Elektrisches Blau (#1a6dff) auf Dunkel — moderner, seriöser
- **Schrift:** Space Grotesk (technisch, klar) oder Inter Bold + Inter Regular
- **Stil:** Präzise, technisch, zuverlässig — wie ein Industriedesign-Magazin
- **Ikonen:** Blitz-Symbol als Markenelement, technische Linien als Dekor

## Must-Haves

- [ ] 24h Notdienst Badge (wie bei Klempner)
- [ ] E-Check / DGUV Prüfung als Trust-Merkmal
- [ ] Zertifizierungen (Meisterbetrieb, VDE, Innungsmitglied)
- [ ] Förderprogramme erwähnen (BAFA, KfW für Photovoltaik / Wärmepumpen)
- [ ] Photovoltaik/Wallbox als separates Angebot wenn vorhanden
- [ ] Festpreise für Standardarbeiten
- [ ] Notdienst-Telefon als primärer CTA

## Leistungen (Standard-Set)

| Leistung | Preis |
|---|---|
| Notdienst (Anfahrt + 1h) | ab 99 € |
| Steckdose installieren | ab 45 € |
| Sicherungskasten prüfen | ab 75 € |
| E-Check (Wohnung) | ab 120 € |
| Beleuchtung installieren | ab 60 € |
| Wallbox installieren | ab 599 € |
| Photovoltaik-Beratung | kostenlos |

## Anti-Patterns

- ❌ Zu viele technische Fachbegriffe ohne Erklärung
- ❌ Preise komplett weglassen (Elektriker sind berüchtigt dafür)
- ❌ Veraltetes Design mit blauen Hintergründen aus 2008
- ❌ Keine Notfall-Nummer sichtbar

## Sektionen-Reihenfolge

1. Hero (Notdienst-Badge, "Ihr Elektriker in [Stadt]", 2 CTAs)
2. Leistungen (3 Karten: Notdienst, Installation, Smart Home/PV)
3. Zertifikate + Trust-Badges
4. Über den Betrieb
5. Bewertungen
6. Kontakt + Einsatzgebiet
7. Footer
