# SKILL: website-builder

## Name
Website Builder für Handwerker

## Description
Erstellt vollständige, responsive HTML/CSS Websites für Handwerksbetriebe. Enthält alle typischen Sektionen: Hero, Leistungen, Über uns, Referenzen, Kontakt. Kein Framework, kein Build-Step — eine einzige `index.html` Datei, die der Kunde sofort hosten kann.

## Trigger-Keywords
- "baue eine Website"
- "erstelle eine Homepage"
- "Website für [Handwerker/Gewerk]"
- "Landing Page"
- "website-builder"

## Anweisungen

### Input sammeln (nur nachfragen wenn nicht angegeben)
- Firmenname
- Gewerk (z. B. Elektriker, Sanitär, Maler, Dachdecker)
- Ort / Region
- Telefonnummer & E-Mail
- Besondere Leistungen oder USPs
- Farbwunsch (sonst: gewerktypische Standardfarbe)

### Aufbau der Website
1. **Hero-Sektion** — großer Titel, Subtext, CTA-Button ("Jetzt anrufen")
2. **Leistungen** — 3–6 Cards mit Icon (Unicode/Emoji), Titel, Kurztext
3. **Über uns** — kurzer Text, Gründungsjahr, Team-Hinweis
4. **Referenzen** — 3 Placeholder-Karten mit Kundenzitat
5. **Kontakt** — Adresse, Telefon, E-Mail, einfaches HTML-Formular
6. **Footer** — Copyright, Impressum-Hinweis

### Technische Anforderungen
- Reines HTML5 + CSS3, kein JavaScript-Framework
- Mobile-first, vollständig responsive (Flexbox/Grid)
- Google Fonts einbinden (z. B. Inter oder Roboto)
- Farbpalette: Primary + Accent + Neutral
- CTA-Button mit hover-Effekt
- Alle Bilder als CSS-Gradient-Placeholder (kein externes Bild-CDN)

### Output
- Eine einzige Datei: `index.html`
- Am Ende kurze Erklärung der Sektionen und wie der Kunde Bilder/Texte austauscht
