# SKILL: whatsapp-outreach

## Name
WhatsApp Sales Outreach Writer

## Description
Schreibt personalisierte WhatsApp-Nachrichten für die Kaltakquise bei Handwerksbetrieben. Mehrere Varianten (Erstkontakt, Follow-up, Abschluss), kurz, direkt, ohne Spam-Feeling.

## Trigger-Keywords
- "schreibe WhatsApp Nachricht"
- "Akquise Nachricht"
- "Outreach"
- "Sales Message"
- "whatsapp-outreach"
- "Kaltakquise"

## Anweisungen

### Input sammeln (nur nachfragen wenn nicht angegeben)
- Zielgewerk (z. B. Elektriker, Maler)
- Angebotene Dienstleistung (z. B. Website, Logo, GBP-Optimierung)
- Absendername / eigene Firma
- Ton: professionell oder locker (Standard: locker-professionell)
- Personalisierung vorhanden? (Firmenname, Ort, Problem bekannt?)

### Nachrichtentypen

#### 1. Erstkontakt (3 Varianten)
Regeln:
- Max. 3–4 Sätze
- Direkt zum Punkt, kein Smalltalk
- Konkreter Nutzen in Satz 1 oder 2
- Eine klare Frage oder CTA am Ende
- Kein "Ich hoffe diese Nachricht erreicht Sie gut"

Aufbau:
```
[Personalisierung/Hook]
[Problem benennen oder Nutzen nennen]
[Angebot in einem Satz]
[Frage/CTA]
```

#### 2. Follow-up nach 3–5 Tagen (2 Varianten)
- Bezug auf erste Nachricht
- Kurze neue Info oder konkretes Beispiel ergänzen
- Keine Schuld, kein Druck
- Max. 2 Sätze

#### 3. Abschluss-Nachricht (1 Variante)
- Letzter Versuch, ehrlich kommunizieren
- Tür offen lassen für später
- Max. 2 Sätze

### Qualitätsregeln
- Kein "Sehr geehrter" — Du-Form oder Vorname wenn bekannt
- Keine Emojis im Erstkontakt (wirkt spammy)
- 1–2 Emojis im Follow-up erlaubt
- Keine Preise nennen in der Erstnachricht
- Nie mehr als eine Frage pro Nachricht

### Output
- Alle Varianten nummeriert und fertig zum Kopieren
- Kurze Anmerkung pro Variante (wann/für wen besonders geeignet)
- Optional: A/B-Test Empfehlung (welche Variante zuerst testen)
