# Maler Website Skill

## Design-Regeln

- **Primärfarbe:** Weiß/Hell auf Dunkel wirkt ironisch und stark — oder Farb-Akzent (#e63946 Rot, #2a9d8f Petrol, #e9c46a Sand)
- **Stil:** Clean, hell und luftig — zeigt handwerkliche Präzision
- **Schrift:** Inter (klar, handwerklich) oder Space Grotesk + Playfair Display für Premium-Effekt
- **Konzept:** Die Website selbst IS das Portfolio — perfekte Layouts = gute Arbeit

## Must-Haves

- [ ] Vorher/Nachher Galerie (Kernstück — Split-Slider oder Grid)
- [ ] Leistungsübersicht mit Preisen (Richtpreise pro m²)
- [ ] Kostenlose Angebotserstellung hervorheben
- [ ] Farb-Beratung als Zusatzleistung erwähnen
- [ ] Referenzprojekte (Anzahl oder Auswahl)
- [ ] Innen- vs. Außenarbeiten klar trennen
- [ ] Meisterbetrieb / Innungsmitglied
- [ ] Angebot innerhalb 24h / 48h versprechen

## Leistungen (Standard-Set)

| Leistung | Preis |
|---|---|
| Innenanstrich (pro m²) | ab 8 € |
| Tapezieren (pro m²) | ab 12 € |
| Fassadenanstrich (pro m²) | ab 18 € |
| Treppenhausrenovierung | auf Anfrage |
| Spachtelarbeiten | ab 15 €/m² |
| Wohnungsübergabe-Renovierung | Pauschal auf Anfrage |

## Anti-Patterns

- ❌ Weiß-auf-Weiß Design (zu generisch für einen Maler)
- ❌ Keine Galerie (das ist das Produkt!)
- ❌ Preise komplett weglassen
- ❌ Zu viele Farben im Design (paradox, aber wahr)

## Sektionen-Reihenfolge

1. Hero (starke Headline + Galerie-Teaser oder Split-Image)
2. Leistungen (Innen / Außen / Sonderprojekte)
3. Vorher/Nachher Galerie
4. Über den Betrieb + Meistertitel
5. Bewertungen
6. Kostenloses Angebot anfordern (prominentes Formular oder WhatsApp)
7. Footer

## Sonder-Feature

Vorher/Nachher Split-Slider: Ein Bild, Drag-Divider zum Vergleichen.
Implementierung: CSS `clip-path` + JS Drag-Event.
