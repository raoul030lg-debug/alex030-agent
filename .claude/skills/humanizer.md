# SKILL: humanizer

## Name
Text Humanizer — Texte klingen menschlich

## Description
Überarbeitet KI-generierte oder steife Texte so, dass sie natürlich, authentisch und menschlich klingen. Entfernt typische KI-Muster, Wiederholungen und Corporate-Sprache. Behält Kernaussage bei, verändert nur Ton und Formulierung.

## Trigger-Keywords
- "mach das menschlicher"
- "klingt zu KI-mäßig"
- "humanizer"
- "natürlicher formulieren"
- "überarbeite den Text"
- "klingt komisch"

## Anweisungen

### KI-Muster erkennen und entfernen
Typische Muster die ersetzt werden müssen:
- "Es ist wichtig zu beachten, dass..." → direkt zur Aussage
- "Im Wesentlichen..." → weglassen
- "Zusammenfassend lässt sich sagen..." → weglassen oder kürzen
- Dreifach-Aufzählungen als Standard-Struktur → variieren
- Jeder Absatz gleich lang → variieren
- Übertriebene Höflichkeit → reduzieren
- Passive Konstruktionen → aktiv formulieren
- Substantivierungen → Verben bevorzugen

### Humanisierungs-Techniken
1. **Satzlänge variieren** — kurze Sätze einstreuen. Auch mal ein längerer Satz der einen Gedanken ausführt und etwas erklärt.
2. **Persönliche Stimme** — "Wir" oder "ich" statt immer "man"
3. **Konkrete Beispiele** statt abstrakte Beschreibungen
4. **Umgangssprache dosiert** — je nach Zielgruppe 1–2 lockere Formulierungen
5. **Gedankensprünge erlauben** — nicht alles perfekt verknüpfen
6. **Rhetorische Fragen** — sparsam einsetzen

### Zielgruppen-Anpassung
- **Handwerker-Kunden:** direkt, kein Fachjargon, bodenständig
- **Business/B2B:** professionell aber nicht steif
- **Social Media:** kurz, energiegeladen, mit Persönlichkeit
- **E-Mail:** freundlich, klar, auf den Punkt

### Prozess
1. Original-Text analysieren: welche KI-Muster vorhanden?
2. Zielgruppe und Tonalität festlegen (oder aus Kontext ableiten)
3. Text überarbeiten (nicht komplett neu schreiben)
4. Check: klingt es wie ein echter Mensch der das wirklich schreiben würde?

### Output
- Überarbeiteter Text
- Optional: 2–3 Sätze was geändert wurde und warum
