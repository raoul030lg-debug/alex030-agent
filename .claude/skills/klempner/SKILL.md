# Klempner Website Skill

## Design-Regeln

- **Primärfarbe:** Gold (#c9a84c) auf Dark (#080808) — Vertrauen + Premium
- **Akzent:** Gedämpftes Blau (#3b6fa0) als zweite Akzentfarbe möglich
- **Schrift:** Playfair Display (Headlines, italic für Impact) + Inter
- **Bildsprache:** Rohre, Werkzeug, saubere Badezimmer, Wasser-Effekte im CSS
- **Ton:** Sachlich, schnell, zuverlässig — kein Marketing-Bullshit

## Must-Haves

- [ ] 24/7 Notdienst Puls-Badge (grüner Dot mit CSS-Animation)
- [ ] Reaktionszeit prominent: "In 45 Min. vor Ort"
- [ ] Festpreise (keine "ab"-Preise ohne konkreten Wert)
- [ ] Notdienst-Aufschlag klar kommunizieren
- [ ] Meisterbetrieb / Innungsmitglied Trust-Badge
- [ ] Google-Bewertungen mit Sternen
- [ ] Standort / Einsatzgebiet (Stadtteile nennen)
- [ ] WhatsApp für Terminbuchung, Telefon für Notfall

## Leistungen (Standard-Set)

| Leistung | Preis |
|---|---|
| Rohrbruch Notdienst (Anfahrt + 1h) | ab 89 € |
| Jede weitere Stunde | 55 € |
| Nacht/Wochenende Aufschlag | +30 € |
| Heizungswartung | ab 120 € |
| Thermostat wechseln | ab 75 € |
| Heizkörper entlüften | ab 45 € |
| Abfluss reinigen | ab 65 € |
| Armatur wechseln | ab 80 € |
| WC-Montage komplett | ab 150 € |

## Anti-Patterns

- ❌ Zu viele Leistungskategorien (max. 3 Hauptkategorien)
- ❌ "Günstig" oder "Billig" als Werbeversprechen
- ❌ Stundenpreise ohne Anfahrtspauschale erklären
- ❌ Formular statt direktem Telefon/WhatsApp

## Sektionen-Reihenfolge

1. Hero (Notdienst-Badge, Headline, 2 CTAs, Trust-Stats)
2. Leistungen (3 Karten: Notdienst, Heizung, Sanitär)
3. Über uns (Meister, Erfahrung, Garantie)
4. Bewertungen (3 Google-Bewertungen)
5. Kontakt + Öffnungszeiten
6. Footer
